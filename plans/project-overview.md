# Project Overview

> Read this file first. It is the single source of truth for what GaadiWalo is, who it serves,
> and what it must do. Every AI agent should load this file before touching any code.

---

## What to put in this file

In this file, write a clear and concise product description so the agent understands the purpose of
GaadiWalo before writing a single line of code. Include:

- **Product name and tagline** – what GaadiWalo is in one sentence.
- **Problem statement** – what pain point the product solves and for whom.
- **Target users** – describe the primary and secondary user personas (e.g., car buyers, dealers,
  service centres) so the agent can make sensible UX and data-model decisions.
- **Core features** – a numbered list of the must-have features for the MVP, written in plain
  language (e.g., "Users can list a vehicle for sale", "Buyers can search by make, model, and
  location"). Keep this to 8–12 items for the MVP.
- **Out of scope for MVP** – list features that are explicitly deferred so the agent doesn't
  accidentally build them.
- **Success metrics** – how you will know the product is working (e.g., number of listings,
  search-to-contact conversion rate).
- **External dependencies** – any third-party services the product relies on (maps, payment
  gateway, SMS provider, etc.) so the agent knows to account for them in the architecture.
